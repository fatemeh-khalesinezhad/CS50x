# CS50x 2026 – Week 0: Scratch

## Overview

This repository contains my Week 0 project for Harvard's CS50x 2026 course. The goal of this week was to learn the fundamentals of computational thinking using Scratch, including events, loops, conditions, variables, and debugging.

## What I Learned

* Breaking a problem into smaller steps
* Event-driven programming
* Using loops to repeat actions
* Making decisions with conditions
* Creating and using variables
* Finding and fixing bugs (debugging)

## Project

**Project Name:** NeuroShift 

A simple puzzle/maze game built in Scratch where the player must navigate through obstacles and reach the goal. The project focuses on applying programming logic rather than creating a complex game.

## Skills Practiced

* Computational Thinking
* Problem Solving
* Scratch Programming
* Game Logic
* Debugging

## Reflection

Week 0 reminded me that programming is not just about writing code—it's about solving problems logically. Although I had previous programming experience, Scratch was a great way to focus on logic without worrying about syntax.
