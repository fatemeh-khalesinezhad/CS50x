# CS50x 2026 — Week 1: C

## Overview

This folder contains my solutions and projects from Week 1 of Harvard University's CS50x course.

In this week, I learned the fundamentals of programming in C, including:

- Variables
- Data types
- Functions
- Conditionals
- Loops
- Problem solving
- Debugging

## Projects

### Hello, World
A simple program that prints a message to the screen.

Concepts practiced:
- Basic C syntax
- Compilation
- Output with `printf`

### Hello, It's Me
A program that asks the user for their name and creates a personalized greeting.

Concepts practiced:
- User input
- Variables
- Strings

### Mario
A program that creates a pyramid pattern using loops.

Concepts practiced:
- Nested loops
- Conditions
- Input validation
- Algorithmic thinking

### Credit
A program that validates credit card numbers using the Luhn algorithm.

Concepts practiced:
- Mathematical logic
- Modulo operations
- Loops
- Data processing

## Key Takeaways

Week 1 was my first experience writing C programs.  
The biggest lesson was understanding how programmers think: breaking large problems into smaller logical steps and translating those steps into code.
